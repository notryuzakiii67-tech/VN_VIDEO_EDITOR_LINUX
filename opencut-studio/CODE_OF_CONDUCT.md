# Code of Conduct

OpenCut Studio is a community project. We want it to be a place where
people can learn, build and ship a genuinely useful editor together.

## Expected behaviour

- Be respectful and constructive; critique ideas and code, not people.
- Welcome newcomers and beginners — this editor is *for* them.
- Assume good faith, explain your reasoning, and accept that
  maintainers may make final calls on design trade-offs.
- Give credit for others' work.

## Unacceptable behaviour

- Harassment, discrimination, or personal attacks in any project space.
- Publishing others' private information.
- Deliberately introducing fake features, fabricated benchmarks, or
  misrepresented test results.
- Knowingly contributing code, assets, fonts or models whose licence
  forbids it.

## Enforcement

Maintainers may remove comments, close issues/PRs, and — for repeated
or serious violations — block participation. Report problems to the
maintainers via the process in `SECURITY.md` (for conduct issues, say
so in the subject) or through GitHub's reporting tools.

This text is an original short-form code of conduct informed by the
spirit of the Contributor Covenant (contributor-covenant.org).
